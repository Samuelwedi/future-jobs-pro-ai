# Coastline data
coastlines.json contains line coordinates derived from world-atlas 2.0.2 land-110m.json (Natural Earth 1:110 million land). Converted with topojson-client 3.1.0; coordinates rounded to 0.001 degrees for display. This is a visual overview, not navigation or survey data.

Natural Earth: https://www.naturalearthdata.com/about/terms-of-use/ — public domain.
World Atlas: https://github.com/topojson/world-atlas — ISC distribution.
The derivative contains geography only; no user coordinates or provider API keys.
