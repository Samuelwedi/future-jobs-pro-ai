Local source continuation, not deployed or included in signed builds 56/10. Public source upload remains blocked by automatic approval review pending explicit payload authorization. No new paid native build, publication, production migration, real provider request, camera capture or physical device test occurred.

Native Evidence adds current-company manager/owner access, paged time-entry inventory, explicit original-file selection, private photo/video/audio/document viewing through the shared viewer, standalone time PDF/GPS/voice reconstruction export, and ZIP generation/sharing. Package forms and hashes clear on account/focus/page changes. Current account/entry validation, fresh connectivity and synchronous locks protect actions; evidence/team/company-administration actions must not replay from offline queues. Mobile ZIPs use a bounded 20 MB authenticated base64 response and private temporary-file sharing/cleanup. Larger ZIPs remain available on the web up to the existing 250 MB package bound. Server-provided ZIP digest is displayed; client envelope validation is not an independent cryptographic authenticity certification.

The API now rechecks active company manager membership for reads, originals and generation, includes owner aliases, scopes recent counts/labels, validates UUIDs/paging/selections and refuses foreign or stale selected IDs instead of silently excluding them. Evidence metadata no longer selects every time-entry column. Company project joins cannot disclose a foreign project's name. Originals are proxied through manager-scoped endpoints with MIME validation. Cloudinary downloads must use HTTPS and the exact configured cloud's upload/private/authenticated paths, omit credentials, reject redirects and HTML errors, and enforce byte limits while streaming. Missing originals/unsupported legacy storage fail explicitly; no unknown origin or S3 key is automatically trusted. Voice reconstruction uses the same bounded original fetch. Archive filenames cannot contain extraction paths. Generated reconstruction failures create bounded warning files; they are not presented as successfully generated video files.

Packages retain selected originals, stored time/GPS metadata, generated artifacts, an artifact index, canonical metadata hash and index seal. A distinct ZIP SHA-256 hashes the actual archive bytes. The existing unsigned hashes detect byte differences when checked against a trusted reference; they do not independently prove physical camera/location/event authenticity or constitute a legal chain-of-custody certification. Web copy and time-record PDFs now say stored records rather than independently verified events. The web evidence list adds pagination and cancels stale reads; package dialogs clear/cancel their old record request.

The shared native viewer now accepts only fixed authenticated chat/support/evidence content routes, uses the returned MIME for playback/sharing and has en/es/fr controls. Evidence's own screen and export errors also have en/es/fr copy. Original file bodies and account tokens are never sent in a GitHub payload.

A related UUID normalization fix prevents uppercase/lowercase representations of one time entry from bypassing invoice duplicate-line detection. Document IDs and linked IDs now use canonical lowercase; a regression test covers the duplicate case.
